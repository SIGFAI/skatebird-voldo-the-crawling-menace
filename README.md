# Voldo the Crawling Menace

**skatebird** × Terraria · enemy · idea by @MrMeow114

A blindfolded, clawed crawler enemy with a Terraria boss health bar creeps around the skate park and lunges at the bird when it skates close. Grinding past it or hopping over it makes it stumble and drop little Terraria coins. Hitting it with a trick combo stuns it for a few seconds.

> I made Voldo, a blindfolded Terraria-style crawler boss for SkateBIRD: hop over him, he trips and spills coins. He did not enjoy the heelflip stun.

## Install

Install BepInEx 5 (64-bit) into your SkateBIRD folder, then copy the BepInEx folder from this mod's release into it and start the game. Voldo wakes up in the Playground level: hop over him or grind past for coins, land a combo to stun him.
